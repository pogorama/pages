Microsoft για την Ελληνική Κοινότητα της Ιρλανδίας

Η Microsoft έχει ένα πρόγραμμα για φιλανθρωπικούς οργανισμούς και μικρούς μη κερδοσκοπικούς συλλόγους. Σχεδόν όλα όσα χρειάζεται ο σύλλογος — email στον τομέα hellenicireland.ie, μια ιστοσελίδα, διαδικτυακές συναντήσεις, τρόποι διαχείρισης μελών και δωρεών, εκπαίδευση για μέλη της κοινότητας και μαθητές — είναι δωρεάν μέσα από αυτό το πρόγραμμα. Αυτή η σελίδα εξηγεί, σε απλά λόγια, τι είναι το κάθε κομμάτι, τι κάνει για τον σύλλογο και πώς να ξεκινήσετε. Δεν χρειάζονται γνώσεις πληροφορικής.

Σύντομη έκδοση

  1. Email, Office και Teams — δωρεάν για έως 300 μέλη της επιτροπής και εθελοντές. Δουλεύει σε οποιοδήποτε πρόγραμμα περιήγησης. (Η Microsoft το ονομάζει Microsoft 365 Business Basic.)
  2. Ένας μικρός διακομιστής στο κέντρο δεδομένων της Microsoft — $2.000 δωρεάν πίστωση ετησίως. Επαρκές για την ιστοσελίδα του συλλόγου, μια βάση δεδομένων μελών και μικρούς αυτοματισμούς. (Η Microsoft το ονομάζει Azure.)
  3. Αυτοματοποίηση επαναλαμβανόμενων εργασιών μεταξύ εφαρμογών (π.χ. όταν φτάνει μια πληρωμή, στέλνεται email ευχαριστίας) — δωρεάν για τις βασικές περιπτώσεις. (Η Microsoft το ονομάζει Power Automate.)
  4. Ένας χώρος για τον κώδικα της ιστοσελίδας — δωρεάν. Ο προαιρετικός βοηθός τεχνητής νοημοσύνης Copilot είναι επί πληρωμή. (Η Microsoft το ονομάζει GitHub.)
  5. Δωρεάν εκπαίδευση για νέα μέλη και δασκάλους — STEM, τεχνητή νοημοσύνη και ψηφιακές δεξιότητες, με κέντρο στο Δουβλίνο και διαδικτυακά. (Η Microsoft το ονομάζει DreamSpace.)
  6. Windows 11 Pro για έως 50 φορητούς υπολογιστές του συλλόγου — μέσω του συνεργάτη TechSoup.

Παρακάτω είναι τι κάνει στην πράξη το πρόγραμμα της Microsoft για τον σύλλογο, ομαδοποιημένο σε τρία πράγματα που ήδη ενδιαφέρουν τον σύλλογο.

1 Email, έγγραφα και συναντήσεις

Τι είναι. Τα καθημερινά εργαλεία που η επιτροπή ήδη χρησιμοποιεί κατά το ήμισυ — email, Word, Excel, PowerPoint, βιντεοκλήσεις και κοινόχρηστα αρχεία — αλλά στον τομέα του ίδιου του συλλόγου (@hellenicireland.ie, για παράδειγμα) και όλα σε ένα μέρος. Η Microsoft πουλάει αυτή τη συλλογή ως Microsoft 365.

Τι κάνει για τον σύλλογο:

  1. Επαγγελματικές διευθύνσεις email για την επιτροπή — treasurer@hellenicireland.ie αντί για προσωπικό Gmail.
  2. Word, Excel και PowerPoint σε οποιοδήποτε πρόγραμμα περιήγησης — για ενημερωτικά δελτία, λογαριασμούς και διαφάνειες για τα μαθήματα ελληνικών.
  3. Βιντεοκλήσεις Microsoft Teams για τις συνεδριάσεις της επιτροπής, με εγγραφή και κοινόχρηστες σημειώσεις.
  4. 1 TB κοινόχρηστου διαδικτυακού αποθηκευτικού χώρου ανά άτομο (η Microsoft το ονομάζει OneDrive) — αντικαθιστά τα συνημμένα email και τα χαμένα στικάκια USB.
  5. Windows 11 Pro για έως 50 φορητούς υπολογιστές του συλλόγου (π.χ. για το σχολείο).

Με τους όρους της Microsoft: Microsoft 365 Business Basic (δωρεάν, έως 300 χρήστες) + Windows 11 Pro (έως 50 άδειες). Λεπτομέρειες ↓

2 Ιστοσελίδα, μητρώα μελών και αυτοματισμός

Τι είναι. Ένας μικρός σύλλογος χρειάζεται επίσης μια ιστοσελίδα, ένα μέρος να κρατάει αρχεία μελών και έναν τρόπο να χειρίζεται τις βαρετές επαναλαμβανόμενες εργασίες αυτόματα. Το cloud της Microsoft (Azure), το εργαλείο αυτοματισμού της Microsoft (Power Automate) και η υπηρεσία αποθήκευσης κώδικα της Microsoft (GitHub) καλύπτουν και τα τρία.

Τι κάνει για τον σύλλογο:

  1. Δημιουργία και φιλοξενία της ιστοσελίδας του συλλόγου — στους διακομιστές της Microsoft, δωρεάν με την πίστωση.
  2. Διατήρηση μιας απλής βάσης δεδομένων μελών (ονόματα, διευθύνσεις, ημερομηνίες ανανέωσης).
  3. Αυτόματη αποστολή του email καλωσορίσματος όταν εγγράφεται ένα νέο μέλος.
  4. Σύνδεση με την τράπεζα ή με Stripe / Revolut, ώστε ο ταμίας να μην καταχωρεί κάθε πληρωμή με το χέρι.
  5. Αποθήκευση του κώδικα και των ρυθμίσεων της ιστοσελίδας σε ένα κοινόχρηστο μέρος όπου μπορούν να συνεργάζονται οι εθελοντές της επιτροπής.

Με τους όρους της Microsoft: Azure (πίστωση $2.000/έτος) + Power Automate (βασικές ροές) + GitHub (δωρεάν άδεια Team). Λεπτομέρειες ↓

3 Εκπαίδευση για μέλη της κοινότητας και μαθητές

Τι είναι. Η Microsoft χρηματοδοτεί επίσης δωρεάν εκπαιδευτικά προγράμματα για φιλανθρωπικούς οργανισμούς, σχολεία και κοινοτικές ομάδες. Διεξάγονται από κέντρο στο Δουβλίνο και διαδικτυακά, και απευθύνονται τόσο σε αρχάριους όσο και σε εκπαιδευτικούς.

Τι κάνει για τον σύλλογο:

  1. Δωρεάν εργαστήρια για μέλη της επιτροπής στα ίδια εργαλεία που χρησιμοποιεί ο σύλλογος.
  2. Συνεδρίες STEM, τεχνητής νοημοσύνης και ψηφιακών δεξιοτήτων για νέα μέλη της κοινότητας (το DreamSpace της Microsoft, με κέντρο στο Δουβλίνο).
  3. Η τεχνητή νοημοσύνη ενσωματωμένη στις καθημερινές εφαρμογές, χωρίς ξεχωριστή απόφαση προμήθειας.
  4. Μαθήματα αυτορρυθμού στο Microsoft Learn — τον δωρεάν διαδικτυακό ιστότοπο μάθησης της Microsoft — για όποιον θέλει να εμβαθύνει σε μια συγκεκριμένη δεξιότητα.
  5. Λειτουργεί παράλληλα με τις επιχορηγήσεις λογισμικού, όχι αντί αυτών.

Με τους όρους της Microsoft: DreamSpace, Changemakers, Microsoft for Nonprofits Community Training. Λεπτομέρειες ↓

Η κορυφαία γραμμή για έναν σύλλογο αυτού του μεγέθους.Με περίπου 40 ενεργά μέλη και επιτροπή μόνο εθελοντών, όλα όσα περιγράφονται παραπάνω είναι δωρεάν για το προβλέψιμο μέλλον. Τα επί πληρωμή επίπεδα έχουν σημασία μόνο όταν ο σύλλογος ξεπεράσει τη δωρεάν επιχορήγηση, και οι μικροί σύλλογοι δεν την ξεπερνούν για πολύ καιρό. Το υπόλοιπο της σελίδας είναι η λεπτομέρεια, με την ίδια σειρά — κλειστή από προεπιλογή.

Επόμενα Βήματα

Επόμενα Βήματα

Τρεις φάσεις — Εγγραφή, Εγκατάσταση, Δόμηση — συν ένα παράλληλο ρεύμα εκπαίδευσης που ξεκινάει από την πρώτη μέρα και δεν σταματάει ποτέ.

1 Εγγραφή

Αποφασίστε ποιος στην επιτροπή είναι υπεύθυνος για κάθε λογαριασμό και μετά κάντε αίτηση. Δύο ονοματισμένοι υπεύθυνοι: ένας για τον λογαριασμό Microsoft για μη κερδοσκοπικούς οργανισμούς και ένας για το Azure. Σημειώστε και τους δύο.

  • Εγγραφή στην σελίδα Microsoft for Nonprofits και ολοκλήρωση του ελέγχου επιλεξιμότητας.
  • Κλείστε μια δωρεάν συνάντηση 1:1 με τη Microsoft Philanthropies μέσω aka.ms/pg, ή μιλήστε με τον Philip το Σάββατο στο μάθημα.

2 Εγκατάσταση

Μόλις γίνει η επαλήθευση, βάλτε τα θεμέλια πριν αρχίσει κανείς να χτίζει.

  • Δημιουργήστε το tenant Microsoft 365 του συλλόγου — τον δικό του ιδιωτικό χώρο μέσα στο cloud της Microsoft — μέσω του κέντρου διαχείρισης, και δώστε άδειες Business Basic στην επιτροπή.
  • Δημιουργήστε τον λογαριασμό Azure και εφαρμόστε την πίστωση $2.000 για μη κερδοσκοπικούς οργανισμούς.
  • Ρυθμίστε το Entra ID — το εργαλείο της Microsoft για τη διαχείριση του ποιος συνδέεται και σε τι έχει πρόσβαση — με ονοματισμένους λογαριασμούς διαχειριστή και έναν εφεδρικό λογαριασμό διαχειριστή κλειδωμένο σε περίπτωση που χαθεί ο κύριος (ονομάζεται λογαριασμός break-glass).
  • Διεκδικήστε το όφελος GitHub for Nonprofits και δημιουργήστε τον οργανισμό GitHub του συλλόγου.

3 Δόμηση

Ξεκινήστε μικρά. Μια δουλειά κάθε φορά. Δείξτε αξία πριν την κλιμάκωση.

  • Διαλέξτε μία επαναλαμβανόμενη εργασία (π.χ. επιβεβαιώσεις εισιτηρίων εκδηλώσεων) και αυτοματοποιήστε την στο Power Automate.
  • Μεταφέρετε την ιστοσελίδα και άλλα μικρά έργα στο Azure, κάτω από την πίστωση των $2.000.
  • Καταχωρείτε κάθε αλλαγή στο GitHub από την πρώτη μέρα — ώστε οποιοδήποτε μέλος της επιτροπής να μπορεί να συνεχίσει εκεί που σταμάτησε ένα άλλο.
  • Επαναλαμβάνετε. Μετράτε. Πληρώνετε για αναβάθμιση μόνο όταν ένας συγκεκριμένος περιορισμός μπλοκάρει μια συγκεκριμένη δουλειά.

Παράλληλα με όλα τα άλλα — από την πρώτη μέρα

Συνεχίστε να μαθαίνετε

Τρέξτε το ρεύμα εκπαίδευσης παράλληλα με Εγγραφή / Εγκατάσταση / Δόμηση. Είναι δωρεάν, είναι συνεχές, και τα μέλη της επιτροπής γίνονται καλύτερα όσο περισσότερο χρησιμοποιούν τα εργαλεία.

  • DreamSpace — δωρεάν συνεδρίες STEM, τεχνητής νοημοσύνης και ψηφιακών δεξιοτήτων για μαθητές, δασκάλους και κοινοτικές ομάδες. Το DreamSpace Dublin φιλοξενεί δια ζώσης συνεδρίες· τα διαδικτυακά προγράμματα τρέχουν όλο τον χρόνο.
  • Microsoft Community Training και ο ευρύτερος κόμβος εκπαίδευσης για μη κερδοσκοπικούς οργανισμούς — από το Δουβλίνο ή διαδικτυακά.
  • Προγράμματα Microsoft Changemakers / Change Agent — προγράμματα ψηφιακών δεξιοτήτων ευθυγραμμισμένα με φιλανθρωπικούς οργανισμούς.
  • Δωρεάν μονοπάτια Microsoft Learn στα βασικά της τεχνητής νοημοσύνης και στο Power Platform.

Ένας κανόνας για όλο το ταξίδι.Πάρτε πρώτα κάθε δωρεάν πράγμα. Πληρώστε για αναβάθμιση μόνο όταν ένας συγκεκριμένος περιορισμός μπλοκάρει μια συγκεκριμένη δουλειά. Σημειώστε το έναυσμα κάθε φορά που αναβαθμίζετε — τα μελλοντικά μέλη της επιτροπής θα πρέπει να δικαιολογήσουν το κόστος.

Ο κανόνας ανάγνωσης — πέντε ερωτήσεις για κάθε δωρεάν προσφορά

Ο κανόνας ανάγνωσης

Διαβάστε κάθε προσφορά μέσα από πέντε ελέγχους.

Πριν δεσμευτείτε σε οποιαδήποτε δωρεάν επιχορήγηση ή έκπτωση, περάστε από αυτές τις πέντε ερωτήσεις. Ο ίδιος φακός εφαρμόζεται σε κάθε προϊόν αυτής της σελίδας.

  1. Τι είναι δωρεάν; — το πραγματικό προϊόν, επιχορήγηση, πίστωση, άδεια ή πρόγραμμα που προσφέρεται.
  2. Τι περιλαμβάνεται; — όρια χρηστών, πιστώσεις, άδειες, λεπτά αυτοματισμού, αποθηκευτικός χώρος, λειτουργίες.
  3. Τι δεν περιλαμβάνεται; — οι λειτουργίες που λείπουν πριν υποθέσετε ότι η δωρεάν προσφορά τις καλύπτει.
  4. Τι προσθέτει η αναβάθμιση; — η επί πληρωμή εναλλακτική, υπολογισμένη ετησίως όταν η τιμολόγηση είναι μηνιαία.
  5. Ποιο είναι το έναυσμα για αναβάθμιση; — η συγκεκριμένη στιγμή που το δωρεάν επίπεδο σταματάει να επαρκεί.

1 · Email, έγγραφα και συναντήσεις — Microsoft 365

1 · Παραγωγικότητα

Microsoft 365

Η δωρεάν επιχορήγηση Microsoft 365 για μη κερδοσκοπικούς οργανισμούς είναι το Business Basic, έως 300 χρήστες. Καλύπτει email, Teams, Office σε πρόγραμμα περιήγησης και κινητό, και 1 TB OneDrive ανά χρήστη. Οτιδήποτε desktop, προηγμένη ασφάλεια ή πλήρες Copilot είναι επί πληρωμή αναβάθμιση.

Δωρεάν  Microsoft 365 Business Basic — μόνο web και κινητό, Outlook, Teams, Word, Excel, PowerPoint, OneNote, Exchange, OneDrive, SharePoint, 1 TB/χρήστη, Copilot Chat περιλαμβάνεται.

Ιδανικό για: email, συναντήσεις, εργασία Office στο πρόγραμμα περιήγησης, βασική κοινή χρήση αρχείων και συνεργασία.

Τι δεν περιλαμβάνεται στη δωρεάν επιχορήγηση Business Basic

Οι desktop εφαρμογές Office δεν αποτελούν μέρος της δωρεάν επιχορήγησης. Οι χρήστες δουλεύουν κυρίως μέσω εφαρμογών προγράμματος περιήγησης και κινητού. Δεν υπάρχει εγκατεστημένο Word, Excel, PowerPoint ή Outlook στο desktop.

Business Standard — $36 / χρήστη / έτος (προσθέτει desktop εφαρμογές)

Τιμή για μη κερδοσκοπικούς, χρέωση ετησίως. Προκύπτει από $3/χρήστη/μήνα × 12. Προσθέτει εγκατεστημένο desktop Office, χρήση χωρίς σύνδεση και μια πλουσιότερη εμπειρία παραγωγικότητας σε desktop — χωρίς το πλήρες πακέτο ασφάλειας και διαχείρισης συσκευών του Business Premium.

Έναυσμα αναβάθμισης: το προσωπικό χρειάζεται εγκατεστημένο Office ή εργασία χωρίς σύνδεση.

Business Premium — $66 / χρήστη / έτος (προσθέτει ασφάλεια & διαχείριση συσκευών)

Τιμή για μη κερδοσκοπικούς, χρέωση ετησίως. Προκύπτει από $5,50/χρήστη/μήνα × 12. Προσθέτει desktop Office, Entra ID, Intune, Defender, Purview, προηγμένη διαχείριση ταυτότητας και πρόσβασης, προστασία από απειλές, ανίχνευση ευαίσθητων δεδομένων και δυνατότητες επιχειρηματικής/ασφάλειας του Windows 11.

Έναυσμα αναβάθμισης: ευαίσθητα δεδομένα, κανονιστική συμμόρφωση, BYOD/MDM ή ισχυρότεροι έλεγχοι ταυτότητας.

Πρόσθετο Microsoft 365 Copilot — $306 / χρήστη / έτος

Πλήρες Microsoft 365 Copilot ως επί πληρωμή πρόσθετο. Προκύπτει από $25,50/χρήστη/μήνα × 12. Προσθέτει βαθύτερη ενσωμάτωση Copilot στις εφαρμογές Microsoft 365. (Το Copilot Chat περιλαμβάνεται ήδη στο Business Basic.)

Έναυσμα αναβάθμισης: οι χρήστες χρειάζονται το Copilot μέσα στις ροές εργασίας Word, Excel, PowerPoint, Outlook, Teams.

Προσοχή με παλαιότερες οδηγίεςΜην υποθέσετε ότι παλιές δωρεάν επιχορηγήσεις για Business Premium ή Office 365 E1 ισχύουν ακόμη. Η τρέχουσα κύρια δωρεάν προσφορά Microsoft 365 είναι το Business Basic, έως 300 χρήστες.

Πηγές: Τιμολόγηση M365 για μη κερδοσκοπικούς · Προσφορές για μη κερδοσκοπικούς · Microsoft Learn

2 · Ο υπολογιστής στο cloud — Azure

2 · Cloud

Azure

Το Azure για μη κερδοσκοπικούς οργανισμούς είναι μια επιχορήγηση πίστωσης $2.000/έτος ανά οργανισμό. Είναι νομισματική πίστωση, όχι άδεια ανά χρήστη και όχι απεριόριστη υπολογιστική ισχύς. Μόλις εξαντληθεί η πίστωση, η χρήση συνεχίζεται με τις στάνταρ τιμές pay-as-you-go.

Δωρεάν  πίστωση Azure $2.000/έτος — αξιοποιήσιμη για φιλοξενία, VMs, βάσεις δεδομένων, αναλυτικά, αποθηκευτικό χώρο, φόρτους εργασίας AI/cloud.

Ιδανικό για: μια μικρή ιστοσελίδα, δύο VMs, μια βάση δεδομένων, ελαφριά αναλυτικά ή μια ελεγχόμενη δοκιμή ενός φόρτου εργασίας AI.

Τι δεν περιλαμβάνεται στη δωρεάν επιχορήγηση Azure

Δεν είναι απεριόριστο Azure. Η χρήση πέρα από $2.000/έτος γίνεται κατανάλωση επί πληρωμή. Η επιχορήγηση είναι πίστωση, όχι ποσόστωση δωρεάν υπολογιστικής ισχύος, αποθηκευτικού χώρου ή χωρητικότητας AI.

Δεν είναι προσφορά βασισμένη σε χρήστες. Δεν υπάρχει αντίστοιχο «δωρεάν για 300 χρήστες» στο Azure. Είναι μία και μοναδική νομισματική πίστωση ανά οργανισμό.

Δεν είναι το ίδιο με τον γενικό δωρεάν λογαριασμό Azure. Η επιχορήγηση για μη κερδοσκοπικούς και ο τυπικός δωρεάν λογαριασμός της Microsoft είναι διαφορετικές προσφορές με διαφορετικούς όρους.

Έναυσμα αναβάθμισης: εξάντληση πίστωσης, Ή ο φόρτος εργασίας είναι αρκετά μεγάλος ώστε τα $2.000/έτος να μην επαρκούν προφανώς και χρειάζεται πραγματική συζήτηση προϋπολογισμού.

Πηγές: Προσφορές Azure · Δωρεάν λογαριασμός Azure

3 · Αυτοματοποίηση επαναλαμβανόμενων εργασιών — Power Automate

3 · Αυτοματισμός

Power Automate

Το Power Automate περιλαμβάνεται σε περιορισμένη μορφή με κάθε άδεια Microsoft 365 — αλλά μόνο με standard connectors. Οτιδήποτε premium, custom, RPA, AI, Dataverse ή unattended απαιτεί επί πληρωμή αδειοδότηση.

Περιλαμβάνεται  Βασικές ροές εργασίας Microsoft 365 με τη χρήση standard connectors (Outlook, SharePoint, Teams, OneDrive, Forms, Lists).

Ιδανικό για: «όταν υποβάλλεται μια φόρμα, αποστολή email»· «όταν δημιουργείται ένα στοιχείο SharePoint, ειδοποίηση στο Teams»· ροές εγκρίσεων· αυτοματισμούς παραγωγικότητας Outlook/SharePoint/Teams.

Τι δεν περιλαμβάνεται στη βασική χρήση Microsoft 365
  • Premium connectors — Salesforce, SAP, ServiceNow, πολλές βάσεις δεδομένων, Azure premium connectors, ενσωματώσεις HTTP/custom API.
  • Custom connectors — οτιδήποτε τυλίγει το δικό σας API.
  • Dataverse — πέρα από τα πολύ περιορισμένα προαπαιτούμενα δικαιώματα.
  • AI Builder — επεξεργασία εγγράφων, πρόβλεψη, ταξινόμηση κειμένου, ανίχνευση αντικειμένων.
  • Πλήρες RPA / αυτοματισμό desktop για κρίσιμη επιχειρηματική χρήση· ιδίως unattended automation.
  • Process και task mining.
Power Automate Premium — $180 / χρήστη / έτος

Χρέωση ετησίως. $15/χρήστη/μήνα × 12. Προσθέτει premium connectors, custom connectors, ροές cloud πέρα από βασικά σενάρια M365, attended desktop flows/RPA, process & task mining, χωρητικότητα AI Builder και δικαιώματα Dataverse.

Έναυσμα αναβάθμισης: οποιαδήποτε ροή χρειάζεται σύστημα μη Microsoft ή premium connector.

Power Automate Process — $1.800 / bot / έτος

$150/bot/μήνα × 12. Προσθέτει unattended automation και βασική αυτοματοποίηση διαδικασιών που τρέχει χωρίς ένα ονομασμένο ανθρώπινο χρήστη να ενεργοποιεί κάθε βήμα.

Έναυσμα αναβάθμισης: ροές εργασίας back-office που πρέπει να τρέχουν τη νύχτα ή χωρίς attended χρήστη.

Power Automate Hosted Process — $2.580 / bot / έτος

$215/bot/μήνα × 12. Ίδιο με το Process, αλλά η Microsoft φιλοξενεί τη χωρητικότητα της μηχανής. Καμία διαχείριση VM από την πλευρά σας.

Έναυσμα αναβάθμισης: χρειάζεστε unattended automation αλλά δεν μπορείτε να διαχειριστείτε τη δική σας υποδομή VM.

Πρακτικός κανόναςΔωρεάν / περιλαμβάνεται: βασικές ροές M365 με standard connectors. Απαιτείται επί πληρωμή: premium connectors, Dataverse, custom APIs, RPA, AI Builder, process mining, unattended automation ή οτιδήποτε σε επιχειρηματική κλίμακα.

Πηγές: FAQ αδειοδότησης · Τύποι αδειών · Τιμολόγηση

4 · Προγράμματα για νέους — DreamSpace

4 · Δεξιότητες

DreamSpace

Το Microsoft DreamSpace είναι ένα δωρεάν πρόγραμμα STEM, AI και ψηφιακών δεξιοτήτων για μαθητές, εκπαιδευτικούς, σχολεία και κοινότητες. Δεν είναι επιχορήγηση άδειας Microsoft 365 και δεν είναι πίστωση Azure. Είναι μια ξεχωριστή, παράλληλη προσφορά που τρέχετε δίπλα στις άλλες.

Δωρεάν  DreamSpace TV, DreamSpace LIVE, Digital Academy, Teacher Academies, βιωματικές εμπειρίες STEM. Προγραμματισμός όλο τον χρόνο για σχολεία.

Ιδανικό για: μη κερδοσκοπικούς οργανισμούς των οποίων η αποστολή περιλαμβάνει εκπαίδευση, νεολαία ή ψηφιακές δεξιότητες κοινότητας — και κάθε μη κερδοσκοπικό που θέλει το προσωπικό του να αναπτύξει δεξιότητες στην τεχνητή νοημοσύνη χωρίς συζήτηση προμηθειών.

Τι δεν είναι το DreamSpace
  • Δεν είναι επιχορήγηση άδειας Microsoft 365 Business Basic / Standard / Premium.
  • Δεν είναι η πίστωση Azure $2.000/έτος για μη κερδοσκοπικούς.
  • Δεν είναι Power Automate Premium, Process, Hosted Process, AI Builder ή premium connectors.
  • Δεν είναι αδειοδότηση GitHub Copilot ή Microsoft 365 Copilot.
  • Δεν υπάρχει όριο «δωρεάν για X χρήστες» — η πρόσβαση βασίζεται στο πρόγραμμα, όχι στην άδεια.

Πρακτικός κανόναςDreamSpace = δωρεάν πρόγραμμα εκπαίδευσης / δεξιοτήτων. DreamSpace ≠ λειτουργική επιχορήγηση άδειας IT. Πάντα να τρέχει παράλληλα με τις προσφορές αδειών.

Windows & εκπαίδευση

Τα Windows 11 Pro διατίθενται ως επιχορήγηση έως 50 αδειών μέσω TechSoup, καθώς και με εκπτωτική τιμολόγηση για επιπλέον άδειες. Η Microsoft δημοσιεύει επίσης δωρεάν πόρους εκπαίδευσης και ανάπτυξης δεξιοτήτων εστιασμένους σε μη κερδοσκοπικούς.

Δωρεάν / επιχορήγηση  Έως 50 άδειες Windows 11 Pro μέσω TechSoup. Δωρεάν πόροι εκπαίδευσης AI και ψηφιακών δεξιοτήτων εστιασμένοι σε μη κερδοσκοπικούς.

Τι δεν περιλαμβάνεται

Η επιχορήγηση Windows έχει ανώτατο όριο 50 αδειών. Πέρα από 50, οι άδειες είναι εκπτωτικές αλλά επί πληρωμή.

Οι πόροι εκπαίδευσης δεν είναι άδειες προϊόντος. Η δωρεάν εκπαίδευση δεν περιλαμβάνει αυτόματα επί πληρωμή πλάνα Microsoft 365, επιπλέον πίστωση Azure, Power Automate Premium, GitHub Copilot ή Microsoft 365 Copilot.

6 · Πού ζει ο κώδικας της ιστοσελίδας — GitHub

6 · Έλεγχος κώδικα

GitHub for Nonprofits

Οι επαληθευμένοι μη κερδοσκοπικοί λαμβάνουν GitHub Team δωρεάν ή 25% έκπτωση στο GitHub Enterprise Cloud. Το Team δίνει απεριόριστους χρήστες και απεριόριστα ιδιωτικά αποθετήρια. Το Copilot δεν περιλαμβάνεται στην επιχορήγηση για μη κερδοσκοπικούς.

Δωρεάν  GitHub Team — απεριόριστα δημόσια & ιδιωτικά αποθετήρια, απεριόριστοι χρήστες, προστατευμένα branches, code owners, draft PRs, Pages, Wikis, environments, 3.000 λεπτά CI/CD/μήνα (≈ 36.000/έτος), 2 GB αποθηκευτικός χώρος Packages.

Ιδανικό για: κάθε μη κερδοσκοπικό που κάνει κώδικα, infra-as-code, αυτοματισμό ή τεκμηρίωση σε έλεγχο εκδόσεων.

Όρια και τι δεν περιλαμβάνεται
  • Δεν είναι GitHub Enterprise Cloud. Το Enterprise προσθέτει data residency, Enterprise Managed Users, SCIM, SAML SSO, Audit Log API, προηγμένο audit, premium υποστήριξη, 50.000 λεπτά CI/CD/μήνα, 50 GB Packages. Οι μη κερδοσκοπικοί λαμβάνουν 25% έκπτωση, όχι δωρεάν.
  • Δεν είναι απεριόριστο CI/CD ιδιωτικών αποθετηρίων. Περιλαμβάνονται 3.000 λεπτά/μήνα· η υπέρβαση χρεώνεται.
  • Το Codespaces δεν είναι απεριόριστο. Το Team περιλαμβάνει πρόσβαση, αλλά η χρήση μετριέται. Τα πλάνα Org/Enterprise δεν περιλαμβάνουν τη δωρεάν ποσόστωση Codespaces του προσωπικού λογαριασμού.
  • Δεν είναι GitHub Copilot. Το Copilot είναι ξεχωριστό προϊόν, δεν περιλαμβάνεται στη δωρεάν προσφορά Team για μη κερδοσκοπικούς.
GitHub Enterprise Cloud — 25% έκπτωση για μη κερδοσκοπικούς

Προσθέτει ελέγχους ασφαλείας, ελέγχους διαχείρισης, data residency, Enterprise Managed Users, SCIM, SAML SSO, Audit Log API, προηγμένο audit, GitHub Connect, premium υποστήριξη, μεγαλύτερη ποσόστωση Actions και μεγαλύτερο χώρο αποθήκευσης Packages.

Έναυσμα αναβάθμισης: SSO απαιτούμενο από την πολιτική IT, ρυθμιζόμενα δεδομένα, audit/συμμόρφωση ή διακυβέρνηση όλου του οργανισμού.

7 · Ο προαιρετικός βοηθός AI — GitHub Copilot

7 · AI κωδικοποίησης

GitHub Copilot

Δεν υπάρχει δωρεάν επιχορήγηση Copilot σε επίπεδο οργανισμού στο πρόγραμμα GitHub for Nonprofits. Μεμονωμένοι developers μπορούν να χρησιμοποιήσουν το περιορισμένο επίπεδο Copilot Free. Από την 1η Ιουνίου 2026, το Copilot μεταβαίνει σε AI Credits βασισμένα στη χρήση πάνω από την τιμή του βασικού πλάνου.

Δωρεάν (ατομικά)  GitHub Copilot Free — 2.000 συμπληρώσεις κώδικα/μήνα και 50 αιτήματα chat / agent-mode/μήνα, ανά μεμονωμένο developer.

Ιδανικό για: έναν μόνο developer που δοκιμάζει το Copilot πριν από τις προμήθειες.

Όρια, τιμολόγηση και η αλλαγή χρέωσης του 2026
  • Δεν είναι στην επιχορήγηση για μη κερδοσκοπικούς. Οι πηγές του GitHub for Nonprofits αναφέρουν δωρεάν Team ή 25% έκπτωση στο Enterprise Cloud. Δεν αναφέρουν Copilot.
  • Το Copilot Free είναι ατομικό και περιορισμένο. Δεν αποτελεί υποκατάστατο για ένα οργανωσιακό πλάνο Copilot.
  • Από την 1η Ιουνίου 2026, το Copilot μεταβαίνει σε AI Credits βασισμένα στη χρήση. Η τιμή του βασικού πλάνου δεν αλλάζει, αλλά η εντατική χρήση μπορεί να κοστίσει περισσότερο από τη σημερινή σταθερή συνδρομή.
Copilot Business — $228 / χρήστη / έτος

$19/χρήστη/μήνα × 12. Τιμή βασικού πλάνου· το GitHub αναφέρει ότι η βασική τιμή δεν αλλάζει καθώς το Copilot μεταβαίνει σε χρέωση βάσει χρήσης.

Copilot Enterprise — $468 / χρήστη / έτος

$39/χρήστη/μήνα × 12. Τιμή βασικού πλάνου· το GitHub αναφέρει ότι η βασική τιμή δεν αλλάζει καθώς το Copilot μεταβαίνει σε χρέωση βάσει χρήσης.

AI Credits βασισμένα στη χρήση (από την 1η Ιουνίου 2026)

Από την 1η Ιουνίου 2026, η χρήση Copilot θα καταναλώνει GitHub AI Credits. Η χρήση πέρα από τις περιλαμβανόμενες ποσοστώσεις μπορεί να απαιτεί πρόσθετη επί πληρωμή χρήση ανάλογα με το πλάνο και τις ρυθμίσεις διαχειριστή.
