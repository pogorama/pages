For committee members of the Hellenic Community of Ireland

Microsoft for the Hellenic Community of Ireland

Microsoft runs a programme for charities and small nonprofits. Almost everything the society needs — email on the hellenicireland.ie domain, a website, online meetings, ways to handle membership and donations, training for community members and students — is free under this programme. This page explains, in plain English, what each piece is, what it does for the society, and how to start. No IT background needed.

The short version

  1. Email, Office and Teams — free for up to 300 committee members and volunteers. Works in any web browser. (Microsoft calls this Microsoft 365 Business Basic.)
  2. A small server in Microsoft's data centre — $2,000 of free credit per year. Plenty for the society's website, a member database and small automations. (Microsoft calls this Azure.)
  3. Automating repetitive jobs between apps (e.g. when a payment lands, send a thank-you email) — free for the basic kind. (Microsoft calls this Power Automate.)
  4. A place to keep the website's code — free. The optional AI helper called Copilot is paid. (Microsoft calls this GitHub.)
  5. Free training for young members and teachers — STEM, AI and digital skills, run from a centre in Dublin and online. (Microsoft calls this DreamSpace.)
  6. Windows 11 Pro for up to 50 society-owned laptops — through a partner called TechSoup.

Three Pillars of Support

Below is what Microsoft's programme actually does for the society, grouped into three things the society already cares about.

1 Email, documents and meetings

What it is. The everyday tools the committee already half-uses — email, Word, Excel, PowerPoint, video calls and shared files — but on the society's own domain (@hellenicireland.ie, for example) and all in one place. Microsoft sells this bundle as Microsoft 365.

What it does for the society:

  1. Professional email addresses for the committee — treasurer@hellenicireland.ie instead of personal Gmail.
  2. Word, Excel and PowerPoint in any web browser — for newsletters, accounts, and slides for Greek classes.
  3. Microsoft Teams video calls for committee meetings, with recording and shared notes.
  4. 1 TB of shared online storage per person (Microsoft calls this OneDrive) — replaces email attachments and lost USB sticks.
  5. Windows 11 Pro for up to 50 society-owned laptops (e.g. for the school).

In Microsoft's words: Microsoft 365 Business Basic (free, up to 300 users) + Windows 11 Pro (up to 50 licences). Detail ↓

2 Website, member records and automation

What it is. A small society also needs a website, somewhere to keep member records, and a way to handle the boring repetitive jobs automatically. Microsoft's cloud (Azure), Microsoft's automation tool (Power Automate) and Microsoft's code-storage service (GitHub) cover all three.

What it does for the society:

  1. Build and host the society's website — on Microsoft's servers, free under the credit.
  2. Keep a simple membership database (names, addresses, renewal dates).
  3. Send the welcome email automatically when a new member signs up.
  4. Connect to the bank or to Stripe / Revolut, so the treasurer does not enter every payment by hand.
  5. Store the website's code and settings in one shared place that committee volunteers can collaborate on.

In Microsoft's words: Azure ($2,000/year credit) + Power Automate (basic flows) + GitHub (free Team licence). Detail ↓

3 Training for community members and students

What it is. Microsoft also funds free training programmes for charities, schools and community groups. They run from a centre in Dublin and online, and are aimed at complete beginners as well as teachers.

What it does for the society:

  1. Free workshops for committee members on the same tools the society itself uses.
  2. STEM, AI and digital-skills sessions for young members of the community (Microsoft's DreamSpace, with a centre in Dublin).
  3. AI brought into the day-to-day apps, without a separate procurement decision.
  4. Self-paced courses on Microsoft Learn — Microsoft's free online learning site — for anyone who wants to deepen a specific skill.
  5. Runs alongside the software grants, not instead of them.

In Microsoft's words: DreamSpace, Changemakers, Microsoft for Nonprofits Community Training. Detail ↓

The headline for a society of this size.With around 40 active members and a volunteer-only committee, everything described above is free for the foreseeable future. The paid tiers only matter when a society outgrows the free grant, and small societies do not, for a long time. The rest of this page is the detail, in the same order — closed by default.

Next Steps

Next Steps

Three phases — Register, Set up, Build — plus a parallel training stream that starts on day one and never stops.

1 Register

Decide who in the committee owns each account, then apply. Two named owners: one for the nonprofit Microsoft account, one for Azure. Write both down.

  • Register on the Microsoft for Nonprofits site and complete the eligibility check.
  • Book a free 1:1 with Microsoft Philanthropies via aka.ms/pg, or talk with Philip on Saturday during class.

2 Set up

Once verified, put the foundations in place before anyone starts building.

  • Create the society's Microsoft 365 tenant — its own private space inside Microsoft's cloud — via the admin centre, and give Business Basic licences to the committee.
  • Create the Azure account and apply the $2,000 nonprofit credit.
  • Set up Entra ID — Microsoft's tool for managing who signs in and what they can access — with named admin accounts and one spare admin account locked away in case the main one is ever lost (called a break-glass account).
  • Claim the GitHub for Nonprofits benefit and create the society's GitHub organisation.

3 Build

Start small. One job at a time. Show value before scaling.

  • Pick one repetitive job (e.g. event-ticket confirmations) and automate it in Power Automate.
  • Move the website and other small projects onto Azure, under the $2,000 credit.
  • Commit every change to GitHub from day one — so any committee member can pick up where another left off.
  • Iterate. Measure. Only pay for an upgrade when a specific limit blocks a specific job.

Alongside everything else — from day one

Keep learning

Run the training stream alongside Register / Set up / Build. It is free, it is continuous, and committee members get better the more they use the tools.

  • DreamSpace — free STEM, AI and digital-skills sessions for students, teachers and community groups. DreamSpace Dublin hosts in-person sessions; online programmes run year-round.
  • Microsoft Elevate for Educators — professional learning for educators who want ready-to-use AI and digital-skills material.
  • Dream Space Ambassador Programme 2026-2027 — for educators who want to champion DreamSpace and STE(A)M activities in their own school or community.
  • DreamSpace & STE(A)M sign-up form and newsletter sign-up form — for programme updates and registration interest.
  • Microsoft Community Training and the wider nonprofit-skilling hub — from Dublin or online.
  • Microsoft Changemakers / Change Agent programmes — digital-skills programmes aligned with charities.
  • Free Microsoft Learn paths on AI fundamentals and Power Platform.

One rule for the whole journey.Take every free thing first. Only pay for an upgrade when a specific limit blocks a specific job. Write down the trigger every time you upgrade — future committee members will need to justify the cost.

The reading rule: five questions to ask about any free offer

The reading rule

Read every offer through five checks.

Before you commit to any free grant or discount, walk through these five questions. The same lens applies to every product on this page.

  1. What is free? — the actual product, grant, credit, licence, or programme being offered.
  2. What is included? — user caps, credits, licences, automation minutes, storage, features.
  3. What is not included? — the missing capabilities before you assume the free offer covers them.
  4. What does the upgrade add? — the paid alternative, annualised, where pricing is monthly.
  5. What is the trigger to upgrade? — the specific moment the free tier stops being enough.

Why this mattersMost procurement mistakes come from one of these checks being skipped. Walk through all five, in order, every time.

1 · Email, documents and meetings: Microsoft 365

1 · Productivity

Microsoft 365

The free Microsoft 365 grant for nonprofits is Business Basic, up to 300 users. It covers email, Teams, browser and mobile Office, and 1 TB OneDrive per user. Anything desktop, advanced security, or full Copilot is a paid upgrade.

Free  Microsoft 365 Business Basic — web and mobile only, Outlook, Teams, Word, Excel, PowerPoint, OneNote, Exchange, OneDrive, SharePoint, 1 TB/user, Copilot Chat included.

Best for: email, meetings, browser-based Office work, basic file sharing and collaboration.

Not included in the free Business Basic grant

Desktop Office apps are not part of the free grant. Users work primarily through browser and mobile apps. No installed Word, Excel, PowerPoint, or Outlook on the desktop.

Business Standard — $36 / user / year (adds desktop apps)

Nonprofit price, billed yearly. Derived from $3/user/month × 12. Adds installed desktop Office, offline use, and a richer desktop productivity experience — without the full security and device-management package of Business Premium.

Upgrade trigger: staff need installed Office or offline work.

Business Premium — $66 / user / year (adds security & device mgmt)

Nonprofit price, billed yearly. Derived from $5.50/user/month × 12. Adds desktop Office, Entra ID, Intune, Defender, Purview, advanced identity and access management, threat protection, sensitive-data discovery, and Windows 11 business/security capabilities.

Upgrade trigger: sensitive data, regulatory compliance, BYOD/MDM, or stronger identity controls.

Microsoft 365 Copilot add-on — $306 / user / year

Full Microsoft 365 Copilot as a paid add-on. Derived from $25.50/user/month × 12. Adds deeper Copilot integration across the Microsoft 365 apps. (Copilot Chat is already included in Business Basic.)

Upgrade trigger: users need Copilot inside Word, Excel, PowerPoint, Outlook, Teams workflows.

Caution about older guidanceDo not assume old free grants for Business Premium or Office 365 E1 still apply. The current mainstream free Microsoft 365 offer is Business Basic, up to 300 users.

Sources: M365 nonprofit pricing · Nonprofit offers · Microsoft Learn

2 · The cloud computer: Azure

2 · Cloud

Azure

Azure for nonprofits is a $2,000/year credit grant per organisation. It is a monetary credit, not a per-user licence and not unlimited compute. Once the credit is exhausted, usage continues at standard pay-as-you-go rates.

Free  $2,000/year Azure credit — usable for hosting, VMs, databases, analytics, storage, AI/cloud workloads.

Best for: a small website, a couple of VMs, a database, light analytics, or a controlled pilot of an AI workload.

Not included in the free Azure grant

Not unlimited Azure. Usage beyond $2,000/year becomes paid consumption. The grant is a credit, not a quota of free compute, storage, or AI capacity.

Not a user-based offer. There is no "free for 300 users" Azure equivalent. It is a single monetary credit per organisation.

Not the same as the general Azure free account. The nonprofit grant and Microsoft's standard free account are different offers with different terms.

Upgrade trigger: credit exhausted, OR the workload is large enough that $2,000/year is clearly not sufficient and you need a real budget conversation.

3 · Automating repetitive jobs: Power Automate

3 · Automation

Power Automate

Power Automate is included in limited form with every Microsoft 365 licence — but only with standard connectors. Anything premium, custom, RPA, AI, Dataverse, or unattended needs paid licensing.

Included  Basic Microsoft 365 workflows using standard connectors (Outlook, SharePoint, Teams, OneDrive, Forms, Lists).

Best for: "when a form is submitted, send an email"; "when a SharePoint item is created, notify Teams"; approval flows; Outlook/SharePoint/Teams productivity automations.

Not included in seeded Microsoft 365 use
  • Premium connectors — Salesforce, SAP, ServiceNow, many databases, Azure premium connectors, HTTP/custom API integrations.
  • Custom connectors — anything wrapping your own API.
  • Dataverse — beyond the very limited seeded entitlements.
  • AI Builder — document processing, prediction, text classification, object detection.
  • Full RPA / desktop automation for business-critical use; unattended automation in particular.
  • Process and task mining.
Power Automate Premium — $180 / user / year

Billed yearly. $15/user/month × 12. Adds premium connectors, custom connectors, cloud flows beyond basic M365 scenarios, attended desktop flows/RPA, process & task mining, AI Builder capacity, and Dataverse entitlements.

Upgrade trigger: any flow that needs a non-Microsoft system or premium connector.

Power Automate Process — $1,800 / bot / year

$150/bot/month × 12. Adds unattended automation and core process automation that runs without a named human user triggering each step.

Upgrade trigger: back-office workflows that should run overnight or without an attended user.

Power Automate Hosted Process — $2,580 / bot / year

$215/bot/month × 12. Same as Process, but Microsoft hosts the machine capacity. No VM management on your side.

Upgrade trigger: you need unattended automation but cannot manage your own VM infrastructure.

Practical ruleFree / included: basic M365 flows with standard connectors. Paid required: premium connectors, Dataverse, custom APIs, RPA, AI Builder, process mining, unattended automation, or anything enterprise-scale.

4 · Programmes for young people: DreamSpace

4 · Skilling

DreamSpace

Microsoft DreamSpace is a free STEM, AI, and digital-skilling programme for students, teachers, schools, and communities. It is not a Microsoft 365 licence grant and not an Azure credit. It is a separate, parallel offer that you run alongside the other ones.

Free  DreamSpace TV, DreamSpace LIVE, Digital Academy, Teacher Academies, immersive STEM experiences. Year-round programming for schools.

Best for: nonprofits whose mission includes education, youth, or community digital skilling — and any nonprofit that wants its staff to upskill in AI without a procurement conversation.

For educators, add Microsoft Elevate for Educators for training material, the Dream Space Ambassador Programme 2026-2027 for deeper participation, and the DreamSpace & STE(A)M sign-up and newsletter forms for updates and registrations.

What DreamSpace is not
  • Not a Microsoft 365 Business Basic / Standard / Premium licence grant.
  • Not the Azure $2,000/year nonprofit credit.
  • Not Power Automate Premium, Process, Hosted Process, AI Builder, or premium connectors.
  • Not GitHub Copilot or Microsoft 365 Copilot licensing.
  • No "free for X users" cap — access is programme-based, not licence-based.

Practical ruleDreamSpace = free education / skilling programme. DreamSpace ≠ operational IT licence grant. Always run it in parallel with the licence offers.

5 · Laptops and Windows licences: Windows 11

5 · Devices & training

Windows & training

Windows 11 Pro is available as a grant of up to 50 licences through TechSoup, plus discounted pricing for additional licences. Microsoft also publishes free nonprofit-focused training and skilling resources.

Free / grant  Up to 50 Windows 11 Pro licences via TechSoup. Free nonprofit-focused AI and digital-skilling training resources.

What is not included

The Windows grant is capped at 50 licences. Beyond 50, licences are discounted but paid.

Training resources are not product licences. Free training does not automatically include Microsoft 365 paid plans, additional Azure credit, Power Automate Premium, GitHub Copilot, or Microsoft 365 Copilot.

6 · Where the website's code lives: GitHub

6 · Source control

GitHub for Nonprofits

Verified nonprofits get GitHub Team free, or 25% off GitHub Enterprise Cloud. Team gives unlimited users and unlimited private repos. Copilot is not part of the nonprofit grant.

Free  GitHub Team — unlimited public & private repos, unlimited users, protected branches, code owners, draft PRs, Pages, Wikis, environments, 3,000 CI/CD minutes/month (≈ 36,000/year), 2 GB Packages storage.

Best for: any nonprofit doing code, infra-as-code, automation, or documentation in version control.

Limits and what is not included
  • Not GitHub Enterprise Cloud. Enterprise adds data residency, Enterprise Managed Users, SCIM, SAML SSO, Audit Log API, advanced auditing, premium support, 50,000 CI/CD min/mo, 50 GB Packages. Nonprofits get 25% off, not free.
  • Not unlimited private-repo CI/CD. 3,000 minutes/month included; overage billed.
  • Codespaces is not unlimited. Team includes access, but usage is metered. Org/Enterprise plans do not include the personal-account free Codespaces quota.
  • Not GitHub Copilot. Copilot is a separate product, not included in the free Team nonprofit offer.
GitHub Enterprise Cloud — 25% nonprofit discount

Adds security controls, admin controls, data residency, Enterprise Managed Users, SCIM, SAML SSO, Audit Log API, advanced auditing, GitHub Connect, premium support, larger Actions allowance, and larger Packages storage.

Upgrade trigger: SSO required by IT policy, regulated data, audit/compliance, or estate-wide governance.

Sources: GitHub Nonprofits · Team docs · Pricing

7 · The optional AI helper: GitHub Copilot

7 · Coding AI

GitHub Copilot

There is no organisation-wide free Copilot grant in the GitHub for Nonprofits programme. Individual developers can use the limited Copilot Free tier. From 1 June 2026, Copilot moves to usage-based AI Credits on top of base plan pricing.

Free (individual)  GitHub Copilot Free — 2,000 code completions/month and 50 chat / agent-mode requests/month, per individual developer.

Best for: a single developer trying Copilot before procurement.

Limits, pricing, and the 2026 billing change
  • Not in the nonprofit grant. The GitHub for Nonprofits sources list free Team or 25% off Enterprise Cloud. They do not list Copilot.
  • Copilot Free is individual and limited. It is not a substitute for an organisational Copilot plan.
  • From 1 June 2026, Copilot moves to usage-based AI Credits. Base plan pricing does not change, but heavy use may cost more than today's flat subscription.
Copilot Business — $228 / user / year

$19/user/month × 12. Base plan price; GitHub says base pricing is not changing as Copilot moves to usage-based billing.

Copilot Enterprise — $468 / user / year

$39/user/month × 12. Base plan price; GitHub says base pricing is not changing as Copilot moves to usage-based billing.

Usage-based AI Credits (from 1 June 2026)

From 1 June 2026, Copilot usage will consume GitHub AI Credits. Usage beyond included allowances may require additional paid usage depending on plan and admin settings.
