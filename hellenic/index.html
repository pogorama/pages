1. Microsoft 365 / Office

Microsoft 365 and Office for nonprofits

M365 pricing Nonprofit offers M365 offers docs
Free offer

Microsoft 365 Business Basic

Free grant for up to 300 users. This is the mainstream free Microsoft 365 offer to focus on.

Includes web and mobile versions of Outlook, Teams, Word, Excel, PowerPoint, OneNote, and other Microsoft 365 web/mobile apps.

Also includes Exchange, OneDrive, SharePoint, Teams, 1 TB cloud storage per user, and Microsoft 365 Copilot Chat at no extra charge as part of Microsoft 365.

Best for

  • Email
  • Teams meetings and chat
  • Browser-based Office work
  • Basic file sharing
  • Basic collaboration
Not included in the free Microsoft 365 Business Basic grant

Desktop Office apps are not included

  • No installed desktop Word
  • No installed desktop Excel
  • No installed desktop PowerPoint
  • No installed desktop Outlook
  • Users mainly work through browser and mobile apps
Microsoft 365 Business Standard$36 /user/year

Nonprofit price shown, billed yearly. Derived from $3/user/month x 12.

Adds desktop Office apps, offline/local Office use, and a richer desktop productivity experience.

Best for: staff who need installed Office apps, offline work, or the familiar desktop Office experience without the full security and device-management package of Business Premium.

Microsoft 365 Business Premium$66 /user/year

Nonprofit price shown, billed yearly. Derived from $5.50/user/month x 12.

Adds desktop Office apps, advanced identity and access management, enhanced cyberthreat protection, sensitive-data discovery/classification/protection, Microsoft Entra ID, Intune, Microsoft Defender, Microsoft Purview, and Windows 11-related business/security capabilities.

Best for: nonprofits handling sensitive data, device management, stronger identity controls, endpoint protection, and compliance tooling.

Microsoft 365 Copilot add-on$306 /user/year

Full Microsoft 365 Copilot is a paid add-on. Derived from $25.50/user/month x 12.

Microsoft 365 Copilot Chat is included with Microsoft 365, but the full add-on adds deeper Copilot integration across Microsoft 365 apps and more advanced productivity assistance.

Best for: users who need Copilot inside productivity workflows across Microsoft 365 apps.

Important caution about older free grants

Do not assume old free grants for Microsoft 365 Business Premium or Office 365 E1 are generally available as current mainstream free nonprofit offers.

The current mainstream free Microsoft 365 offer to focus on is Microsoft 365 Business Basic free up to 300 users.

2. Azure

Azure for nonprofits

Azure offers Azure free account
Free offer

Azure nonprofit grant

$2,000/year in Azure credits. This is an organisation-level annual grant, not a per-user licence.

It can be used for Azure services such as hosting websites, virtual machines, databases, analytics, cloud infrastructure, and AI/cloud workloads.

Paid alternative / after the grant

After the annual Azure credit is consumed, usage becomes paid Azure consumption unless the organisation stops, caps, or changes usage.

Paid Azure adds continued cloud usage beyond the grant, the ability to scale workloads beyond the free annual credit, and access to more Azure services as normal paid consumption.

Not included in the free Azure grant

Not unlimited Azure

  • Usage beyond the $2,000/year credit becomes paid Azure consumption.
  • The grant is a credit amount, not unlimited VM or compute usage.
  • Storage usage consumes credit and can become paid once the grant is exhausted.
  • AI/cloud workloads consume Azure credit like other eligible services.

Not a user-based offer

  • There is no "free for 300 users" equivalent for Azure in this grant.
  • It is a monetary credit grant.

Not the same as the general Azure free account

Azure free account offers and the nonprofit Azure grant are separate offers with separate terms.

3. Power Automate

Power Automate for nonprofits

Licensing FAQ Licence types Pricing
Free / included use

Seeded Microsoft 365 use

Power Automate is included in limited form with Microsoft 365 licences. Microsoft 365 users can use Power Automate with standard connectors.

This means Microsoft 365 Business Basic grant users can use basic Power Automate scenarios where flows stay within included Microsoft 365 and standard connector rights.

Suitable free/basic scenarios

  • When a Form is submitted, send an email
  • When a SharePoint item is created, notify a Teams channel
  • Approval flows using standard connectors
  • Outlook, SharePoint, Teams, and OneDrive productivity automations
Not included in the free / Microsoft 365-seeded Power Automate rights

Premium connectors are not included

Premium connector scenarios require standalone Power Apps or Power Automate licensing. Examples that often require premium rights include some database connections, ERP/CRM systems, Salesforce, SAP, ServiceNow, Azure premium connectors, and HTTP/custom API-style integrations.

Custom connectors are not included

Connecting to custom APIs or bespoke systems requires paid licensing.

On-premises and advanced connector scenarios are not included

Premium, on-premises, and custom connector scenarios require standalone Power Apps or Power Automate licensing.

Full Dataverse scenarios are not included

Microsoft Dataverse connector is listed as Premium for Power Automate and Power Apps.

AI Builder is not included

Document processing, prediction, text classification, object detection, and similar AI Builder scenarios require paid licensing or capacity.

Full RPA / desktop automation is not included for business-critical use

Full cloud and desktop automation requires paid Power Automate licensing. Unattended automation requires Process or Hosted Process licensing.

Process mining / task mining is not included

These are paid Power Automate capabilities and are not included in the free/basic seeded use.

Power Automate Premium$180 /user/year

Billed yearly. Derived from $15/user/month x 12.

Adds premium connectors, custom connectors, cloud flows beyond basic Microsoft 365 scenarios, attended desktop flows/RPA, process mining/task mining capabilities, AI Builder capacity, and Dataverse entitlements.

Best for: power users, automation builders, and nonprofits integrating with systems outside standard Microsoft 365 connectors.

Power Automate Process$1,800 /bot/year

Billed yearly. Derived from $150/bot/month x 12.

Adds unattended automation and core process automation that runs without a named human user directly triggering everything.

Best for: back-office automation, repeatable operational workflows, and bot-style automation.

Power Automate Hosted Process$2,580 /bot/year

Billed yearly. Derived from $215/bot/month x 12.

Adds unattended automation, Microsoft-hosted machine capacity, and less need to manage your own automation infrastructure.

Best for: nonprofits that need unattended automation but do not want to manage their own machine or VM infrastructure.

Practical Power Automate rule

Free/included: basic Microsoft 365 workflows with standard connectors.

Paid required: premium connectors, Dataverse, custom APIs, RPA, AI Builder, process mining, unattended automation, or enterprise-scale automation.

Dream Space != operational IT licence grant.

6. GitHub

GitHub for Nonprofits

GitHub nonprofits Team docs Pricing
Free offer

Free GitHub Team or 25% off Enterprise Cloud

Eligible verified nonprofits can get free GitHub Team or 25% off GitHub Enterprise Cloud.

GitHub states eligible nonprofits can receive a free GitHub Team plan with unlimited private repositories and unlimited users.

What free GitHub Team includes

  • Unlimited public repositories
  • Unlimited private repositories
  • Protected branches and repository rules
  • Multiple reviewers in pull requests
  • Code owners and required reviewers
  • Draft pull requests, Pages, and Wikis
  • Environment deployment branches and secrets
  • Web-based support

Automation and package allowance

  • 3,000 CI/CD minutes/month
  • Equal to 36,000 CI/CD minutes/year
  • 2 GB Packages storage
  • GitHub Actions usage is free for public repositories using standard GitHub-hosted runners
  • GitHub Actions usage is free for self-hosted runners

Codespaces access

GitHub Team includes access to GitHub Codespaces, but Codespaces usage itself should be checked against current GitHub pricing and billing terms.

Not included / limitations of free GitHub Team

Not GitHub Enterprise Cloud

Enterprise Cloud is not free under the nonprofit offer. Nonprofits get 25% off GitHub Enterprise Cloud.

Enterprise Cloud adds data residency, Enterprise Managed Users, SCIM provisioning, enterprise account management, Audit Log API, SAML single sign-on, advanced auditing, GitHub Connect, premium support, 50,000 CI/CD minutes/month, and 50 GB Packages storage.

Not unlimited private-repository CI/CD

GitHub Team includes 3,000 CI/CD minutes/month. Usage beyond included amounts can be billed for private repositories.

Codespaces is not unlimited free

GitHub Team includes access to Codespaces. GitHub pricing also lists Codespaces as usage-based, starting at $0.18/hour compute and $0.07/GB storage. GitHub Docs state organisation and enterprise plans do not include a free GitHub Codespaces quota; free quota is described for personal accounts.

Not GitHub Copilot Business or Enterprise

GitHub for Nonprofits gives free GitHub Team or 25% off GitHub Enterprise Cloud. The sources do not state that GitHub Copilot is included in the free GitHub Team nonprofit offer. GitHub pricing lists Copilot separately from GitHub Team.

GitHub Enterprise Cloud paid alternative25% nonprofit discount

GitHub Enterprise Cloud: 25% nonprofit discount. Adds additional security controls, admin controls, customisation options, data residency, Enterprise Managed Users, SCIM provisioning, enterprise account management, Audit Log API, SAML single sign-on, advanced auditing, GitHub Connect, premium support, larger Actions allowance, and larger Packages storage.

7. GitHub Copilot

GitHub Copilot

Copilot plans Billing blog Docs
Free / included offer

No nonprofit organisation-wide free Copilot plan found

GitHub for Nonprofits sources mention free GitHub Team or 25% off GitHub Enterprise Cloud. They do not state that GitHub Copilot is included.

GitHub Copilot Free

Available to individual developers with limited usage: 2,000 code completions/month and 50 chat / agent-mode requests/month.

This is not the same as a nonprofit organisation-wide Copilot grant.

GitHub Copilot Business$228 /user/year

Public GitHub blog states base plan price: $19/user/month.

GitHub says base plan pricing is not changing as Copilot moves to usage-based billing from 1 June 2026.

GitHub Copilot Enterprise$468 /user/year

Public GitHub blog states base plan price: $39/user/month.

GitHub says base plan pricing is not changing as Copilot moves to usage-based billing from 1 June 2026.

Usage-based AI CreditsPaid overage risk

From 1 June 2026, Copilot usage will consume GitHub AI Credits. Usage beyond included allowances may require additional paid usage depending on plan and admin settings.

Not included and important Copilot limitations
  • GitHub Copilot is not included in the free GitHub Team nonprofit grant based on the public sources found.
  • GitHub Copilot Free is limited and individual-oriented.
  • It should not be presented as a full nonprofit organisational Copilot grant.
  • From 1 June 2026, Copilot billing changes to usage-based AI Credits, so heavy usage may cost more than the base subscription price.
8. Practical recommendation

Quick practical recommendation

Good free starting point
  • Microsoft 365 Business Basic free for up to 300 users
  • Azure $2,000/year grant
  • Basic Power Automate with standard Microsoft 365 connectors
  • GitHub Team free if code/project collaboration is needed
  • Dream Space if the need is student, teacher, or community digital skilling
Upgrade triggers
  • Desktop Office apps: Microsoft 365 Business Standard, $36/user/year
  • Security, device management, compliance, identity protection: Microsoft 365 Business Premium, $66/user/year
  • Full Microsoft 365 Copilot: Microsoft 365 Copilot, $306/user/year
  • Premium automation, Dataverse, RPA, AI Builder, custom connectors: Power Automate Premium, $180/user/year
  • Unattended automation: Power Automate Process, $1,800/bot/year
  • Microsoft-hosted unattended automation: Power Automate Hosted Process, $2,580/bot/year
  • Enterprise GitHub governance/security/SSO/audit/data residency: GitHub Enterprise Cloud, 25% nonprofit discount
  • Coding AI at organisational scale: GitHub Copilot Business or Enterprise, not included in free GitHub Team nonprofit grant
